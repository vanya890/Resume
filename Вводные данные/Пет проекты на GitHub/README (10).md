# Stroy-Materiali-24.ru

## Полное описание
Проект для работы с сайтом строительных материалов 24.ru. Включает инструменты SEO-оптимизации, парсинга, генерации контента и анализа ключевых запросов.

## Архитектура
- **Скрипты**: fix_markdown.py для обработки Markdown, парсеры для CSV (популярные запросы).
- **Папки**: Extention (расширения), Prompt (промпты для AI), Publicated (опубликованный контент).
- **Данные**: CSV-файлы с аналитикой вебмастера.
- **Flow**: Парсинг → обработка Markdown → публикация.

## Технологии
Python, pandas, requests и т.д. (requirements.txt).
