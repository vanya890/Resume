# EduRoboSim: Образовательный 3D-симулятор робототехники

**Тема ВКР:** Разработка образовательного симулятора для изучения основ робототехники

## 1. Аннотация проекта
**EduRoboSim** — это специализированное программное обеспечение, предназначенное для обучения студентов и школьников основам робототехники, алгоритмизации и физики твердого тела. Проект представляет собой 3D-симулятор, в котором пользователь управляет виртуальным роботом, используя специально разработанный язык программирования (DSL).

В отличие от существующих решений, проект сфокусирован на "чистом коде" и модульности. Отказ от тяжеловесных игровых движков в пользу стека **Tauri + React + Three.js** позволил создать легковесное, быстрое и современное приложение, которое идеально подходит для образовательных целей.

---

## 2. Технологический стек
Для реализации проекта выбран современный стек, обеспечивающий высокую производительность и удобство разработки:

*   **Desktop Framework:** [Tauri](https://tauri.app/) (Rust + WebView2). Обеспечивает нативную интеграцию с Windows, малый размер дистрибутива и безопасность.
*   **Frontend:** React 18 + TypeScript. Обеспечивает компонентный подход к построению UI.
*   **3D-графика:** React Three Fiber (R3F) + Three.js. Декларативный рендеринг 3D-сцены.
*   **Физический движок:** Собственная 2D коллизия (OBB) на плоскости XZ для стабильности и производительности.
*   **Редактор кода:** Monaco Editor (ядро VS Code).
*   **Язык программирования:** Собственный интерпретатор (EduScript), реализованный на TypeScript.

## 3. Архитектура системы
Проект спроектирован с использованием паттерна **MVC (Model-View-Controller)** и принципов **SOLID**.

### 3.1. Структура проекта
```text
EduRoboSim/
├── src/
│   ├── core/               # Ядро: коллизии, загрузка уровней, контроллер робота
│   ├── interpreter/        # Парсер и виртуальная машина EduScript
│   ├── components/         # React-компоненты (UI, 3D-сцена, Редактор)
│   ├── store/              # Глобальное состояние (Zustand)
│   ├── types/              # Типы TypeScript
│   └── utils/              # Логирование
├── public/
│   ├── levels/             # YAML-уровни
│   ├── instructions/       # Markdown-инструкции к уровням
│   └── monaco-editor/      # Локальная копия Monaco Editor
├── src-tauri/              # Rust-бэкенд: файловая система, окна
│   └── icons/              # Иконки приложения
└── package.json
```

### 3.2. Подсистема интерпретатора (EduScript)
Для обеспечения образовательной ценности разработан собственный язык **EduScript**.
1.  **Лексический анализатор:** Разбивает строку кода на токены.
2.  **Парсер (AST):** Строит дерево абстрактного синтаксиса.
3.  **Виртуальная машина:** Исполняет дерево команд, взаимодействуя с API робота через очередь событий.
4.  **Безопасность:** Изолированная среда выполнения предотвращает доступ к системным файлам ОС.

## 4. Функциональные возможности

### 4.1. Физическая модель
*   **Дифференциальный привод:** Два независимых мотора, кинематика на плоскости XZ.
*   **Коллизии:** 2D OBB-коллизия со скольжением вдоль стен (3 итерации разрешения). Трансформация координат с учётом ротации препятствий (Three.js Y-axis rotation).
*   **Сенсоры (кольцо из 8 дальномеров):**
    *   *Дальномеры:* 8 ультразвуковых датчиков по кругу (Ф, ПП, П, ЗП, З, ЗЛ, Л, ФЛ), raycast до 4м.
    *   *Энкодер:* Интеграция линейной скорости для расчета пройденного пути.
    *   *Гироскоп:* Угол поворота робота в градусах.
    *   Визуализация: красные маркеры датчиков на корпусе + цветные лучи (зелёный > 2м, жёлтый < 2м, красный < 1м).
*   **Материалы:** Геометрические примитивы с цветовым кодированием (без текстур).

### 4.2. Выбор робота
*   **Квадратный:** 4 колеса (радиус 0.12м), устойчивый, жёлтый корпус (0.6×0.3×0.8м). Колёса касаются пола, корпус перекрывает верхнюю половину.
*   **Круглый:** 2 колеса (радиус 0.10м) + опорный шарик, маневренный, синий корпус-диск с куполом (радиус 0.35м). Колёса касаются пола.

### 4.3. Редактор уровней
*   Визуальный интерфейс для расстановки объектов (Floor, Wall, Ramp, Bump, Trigger).
*   Сохранение и загрузка уровней в формате **YAML** (человекочитаемый текст).

### 4.4. Образовательный модуль
*   Кнопка "Инструкция" открывает встроенный Markdown-вьювер.
*   Привязка инструкций к конкретным уровням через YAML-конфигурацию.

## 7. Инструкция по сборке и запуску

### 7.1. Требования
*   Установленный [Node.js](https://nodejs.org/) (v18+).
*   Установленный [Rust](https://rustup.rs/).
*   Visual Studio C++ Build Tools (для компиляции Rust-кода под Windows).

### 7.2. Локальная разработка
```cmd
# Клонирование репозитория
git clone <url>
cd EduRoboSim

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run tauri dev
```

Для доступа из локальной сети используется `host: "0.0.0.0"` в `vite.config.ts`. Адрес отображается в консоли при запуске.

### 7.3. Сборка дистрибутива
```cmd
# Сборка .exe и установщика
npm run tauri build
```
*   Исполняемый файл будет доступен в директории `src-tauri\target\release\bundle\`.
