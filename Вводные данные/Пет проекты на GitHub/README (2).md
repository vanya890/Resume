# P2P VPN DHT

P2P VPN для Windows на базе DHT (Kademlia) и Peer Exchange (PEX). Без STUN, без relay-серверов.

## Архитектура

```
┌─────────────────────────────────────────────┐
│              Приложение (C#)                 │
├──────────┬──────────┬──────────┬────────────┤
│  DHT     │   PEX    │  Crypto  │  TUN/TAP   │
│ Kademlia │ Protocol │  Noise   │  (Wintun)  │
├──────────┴──────────┴──────────┴────────────┤
│              UDP Socket (IPv4/IPv6)          │
└─────────────────────────────────────────────┘
```

## Компоненты

- **DHT (Kademlia)** — децентрализованная таблица хэшей для обнаружения пиров
- **PEX (Peer Exchange)** — обмен списками пиров между подключёнными узлами
- **Crypto (Noise Protocol)** — шифрование всего трафика (ChaCha20-Poly1305)
- **TUN Adapter (Wintun)** — виртуальный сетевой адаптер для создания VPN-сети

## Быстрый старт

```bash
# Сборка
dotnet build -c Release

# Запуск
P2pVpnDht.exe --network mynet --key <private-key>

# Присоединиться к сети через bootstrap-пира
P2pVpnDht.exe --network mynet --key <private-key> --bootstrap 192.168.1.100:9876
```

## Как это работает

1. Каждый узел генерирует Ed25519 ключевую пару
2. NodeID = SHA256(public_key) — 256-битный идентификатор в DHT
3. Узел подключается к bootstrap-пирам через UDP
4. DHT находит других пиров в сети
5. PEX распространяет списки пиров
6. Между пирами устанавливается зашифрованный туннель
7. Виртуальный адаптер создаёт L3 сеть (каждый пир получает IP из пула)
