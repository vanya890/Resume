## Приватность

Из публичной копии намеренно исключены дата рождения, код студента, внутренние номера приказов, сведения из личного кабинета, изображения экрана и другие реквизиты, которые не нужны работодателю для оценки квалификации.

Оригинальная выписка из личного кабинета не хранится в публичном репозитории. Для подтверждения образования предоставляется актуальный документ напрямую работодателю.
