# Lab5 - Технологии визуализации данных систем управления

## Описание

Лабораторная работа №5 по дисциплине "Технологии визуализации данных в системах управления".

**Цель:** Изучить современные инструменты и технологии визуализации данных для систем контроля и управления.

## Содержимое репозитория

- **Lab4/** — исходный код лабораторной работы (C# проект).
- **Creator.xlsx**, **CreatorBlank.xlsx** — шаблоны и данные для генерации.
- **saved.csv**, ***.txt** — сохраненные данные и логи.
- **.sln** — решение Visual Studio.

## Технологии

- **C# / .NET**
- **Visual Studio**
- **Excel** для обработки данных
- **Git** для контроля версий

## Инструкция по запуску

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vanya890/Lab5-Control-system-data-visualization-technologies.git
   ```
2. Откройте `Lab4.sln` в Visual Studio.
3. Соберите и запустите проект.
