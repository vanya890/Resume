# AirCody

## Полное описание проекта
AirCody — это desktop-приложение с графическим интерфейсом на Python, предназначенное для работы с AI-моделями, потоковой обработкой данных (streaming), интеграцией с внешними API и визуализацией результатов в реальном времени. Проект подходит для демонстрации, тестирования и практического применения технологий искусственного интеллекта в удобном GUI.

## Архитектура проекта (подробно)
Проект следует принципам separation of concerns (разделения ответственности):
- **main.py**: Точка входа приложения. Инициализирует GUI, запускает основной цикл и управляет состоянием.
- **gui.py**: Реализация пользовательского интерфейса (окна, кнопки, поля ввода, отображение логов/результатов). Использует Tkinter или подобную библиотеку для кросс-платформенности.
- **streaming.py**: Модуль для обработки потоковых данных — подключение к AI API (например, OpenAI-like streaming), обработка чанков ответов, асинхронная работа.
- **__pycache__**: Кэш байт-кода (игнорируется в .gitignore).
- **.gitignore**: Стандартные исключения для Python-проектов.

**Общая схема потока**:
1. Пользователь вводит промпт/данные в GUI.
2. main → streaming модуль отправляет запрос.
3. Получение streamed response в реальном времени.
4. Отображение в GUI + логирование.

**Преимущества архитектуры**: Легко расширять (добавлять новые streaming-провайдеры), тестировать модули независимо, поддерживать UI отдельно от логики.

## Технологический стек
- Python 3.x
- Tkinter (или PyQt) для GUI
- Requests / aiohttp для API
- Возможно asyncio для асинхронного streaming

## Полная установка
1. Клонируйте: `git clone https://github.com/vanya890/AirCody.git`
2. `cd AirCody`
3. `python -m venv venv`
4. Активируйте venv
5. `pip install -r requirements.txt` (если есть; иначе requests, tkinter)
6. `python main.py`

## Использование
- Запустите приложение.
- Введите запрос в поле.
- Нажмите "Stream" — наблюдайте за ответом в реальном времени.
- Логи в консоли/GUI.

## Troubleshooting
- Проблемы с GUI: проверьте Tkinter установку.
- API ошибки: настройте ключи в .env.
