# Kursach6Sem

## Полное описание курсового проекта
Курсовой проект 6 семестра — Windows Forms приложение на C#. Включает графический интерфейс (Form1), обработку видео (файлы с перекрестком в Сибуя, Япония), инфраструктурные классы, конфигурацию и ресурсы. Цель — демонстрация навыков разработки desktop-приложений, работы с медиа, GUI и .NET.

## Архитектура (детально)
- **Project/**: Основная папка решения.
- **Form1.cs / Designer.cs / resx**: Главная форма с дизайном, событиями, ресурсами (иконки, строки).
- **Program.cs**: Точка входа.
- **Infrastructure/**: Вспомогательные классы (возможно, для видео-обработки, логики).
- **Properties/**: Настройки сборки.
- **Videos**: istockphoto...mp4 и Япония...mp4 — медиа-активы для плеера или анализа.
- **.vs, obj, packages**: Вспомогательные для VS и NuGet.
- **.sln / .csproj**: Решение и проект-файлы.

**Поток работы**: Запуск → GUI Form → загрузка/воспроизведение видео → обработка (если реализовано).

## Технологии
C# .NET Windows Forms, Visual Studio, возможно MediaPlayer controls.

## Установка и запуск
1. Клонировать.
2. Открыть .sln в Visual Studio.
3. Restore packages.
4. Build & Run.

## Функционал
Описание возможных фич на основе файлов (плеер видео, интерфейс).
