Курсовой проект: Программная обработка данных мониторинга

Инструкция по запуску:
1. Откройте решение Project.sln в Visual Studio.
2. Соберите и запустите проект.
3. В открывшемся окне нажмите кнопку "Загрузить данные".
4. Программа автоматически загрузит файл DataCP_v1.csv (должен находиться в папке с исполняемым файлом, обычно bin/Debug).
5. Результаты анализа будут представлены на вкладках:
   - Статистика: Описательная статистика по шкалам, исключение выбросов, квалификационные уровни.
   - Корреляция и Факторы: Корреляционная матрица, собственные значения и векторы (факторный анализ).
   - Кластерный анализ: Дендрограмма кластеризации участников (показаны первые 50 для наглядности).
   - Качество теста: График распределения заданий по сложности и дифференцирующей способности.
   - Оптимизация: Рекомендации по улучшению теста на основе анализа заданий.

Структура проекта:
- Models/TestResult.cs: Модель данных результата теста.
- Models/ScaleRules.cs: Правила начисления баллов по шкалам.
- Services/DataService.cs: Загрузка и парсинг CSV.
- Services/StatisticsService.cs: Расчет статистики, выбросов, параметров заданий.
- Services/AnalysisService.cs: Корреляционный, факторный и кластерный анализ.
- Form1.cs: Основная форма, логика отображения и визуализации.

Примечание:
Все алгоритмы реализованы вручную без использования сторонних математических библиотек.
