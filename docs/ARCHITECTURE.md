# Архитектура данных резюме

## Источники истины
- `data/profile.json`: публичные контакты и образование.
- `data/projects.json`: проекты, публичность, ссылки, стек и результаты.
- `data/skills.json`: навыки и ссылки на проекты-доказательства.
- `data/resume-profiles.json`: целевые роли и правила отбора проектов для шести резюме.

`MasterData/Все_навыки.md` — инвентаризация, не источник публикации без проверки.

## Правила достоверности
1. У проекта уникальный стабильный `id`.
2. Навык без подтверждающего проекта не считается доказанным.
3. Уровень не выводится из наличия проекта. Уровни заполняются после самооценки и проверки примеров.
4. Каждый вариант резюме имеет целевую роль и явный список проектов.
5. Исходные документы об образовании не публикуются.

## Миграция на Typst
LaTeX остаётся production-генератором до сравнения шести документов. Typst должен читать тот же источник данных; переход допускается после проверки текста, шрифтов, переносов, страниц, ATS-порядка и визуальной верстки. HTML-экспорт Typst пока экспериментальный и не используется для сайта.
