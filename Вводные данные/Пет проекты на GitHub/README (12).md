# Lab2-AI-3Curs

## Полное описание
Лабораторная работа №2 по курсу "Искусственный интеллект" (3 курс). Проект включает реализацию алгоритмов ИИ, обработку данных, создание моделей, отчеты (docx/pdf) и вспомогательные файлы (xlsx, txt, sln для C# компонентов).

## Архитектура
- **Основные файлы**: Creator.xlsx / CreatorBlank.xlsx — шаблоны данных; Digital.txt, 64map.txt — наборы данных; Lab4.sln + Lab4/ — C# проект; saved.csv — результаты.
- **Отчеты**: Кузык Иван КП.docx/pdf — полный отчет с описанием, кодом, выводами.
- **Структура**: Смешанный проект (Python/C#), фокус на генерации/обработке данных для ИИ-задач.

## Технологии
C#, Python, Excel, data processing.

## Установка и запуск
Подробные шаги для открытия .sln, запуска скриптов, генерации отчетов.

## Анализ кода и результаты
Описание ключевых компонентов, примеры вывода.
