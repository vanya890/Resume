# InfinityAI Novel 🎮

AI-driven interactive visual novel game. Stories are generated by AI, characters have AI-generated portraits, and every choice shapes the narrative.

## ✨ Features

- 🤖 **AI Story Generation** — OpenRouter API or local LM Studio generates unique narratives
- 💻 **Local AI Support** — Full LM Studio integration with JSON Schema structured output
- 🎨 **AI Character Portraits** — Local ComfyUI generates character art
- 🧠 **Smart Character Creation** — AI generates complete character cards with fallback parsing for truncated responses
- 📝 **Custom Scenarios** — Create your own worlds, characters, and stories
- 💬 **Chat/Save System** — Auto-saves every turn, continue anytime
- ⚙️ **Full Settings** — AI model selection, reasoning mode, temperature, response length
- 📱 **Mobile Friendly** — Works on any device via local network
- 💾 **Server-Side Storage** — Character data persisted on server with client-side cache verification

## 🚀 Quick Start

```bash
npm install
cp .env.example .env    # Add your OpenRouter API key
npm run dev             # http://localhost:5173
```

### Local AI with LM Studio

1. Download and install [LM Studio](https://lmstudio.ai/)
2. Load a model (e.g., Qwen 3.5 9B)
3. Start the local server (default: port 1234)
4. In game settings, select **LM Studio** mode and set URL to `http://localhost:1234`
