# NumberMethods

## Обзор проекта
Этот репозиторий содержит полный набор лабораторных работ по дисциплине "Численные методы" для студентов. Здесь реализованы классические алгоритмы численного анализа, включая решение систем линейных алгебраических уравнений (СЛАУ), интерполяцию, численное дифференцирование и интегрирование, аппроксимацию функций и многое другое.

## Архитектура проекта
Проект построен по модульному принципу:
- **Корневая структура**: Папки `Лаб1`, `Лаб2`, ..., `Лаб6` — каждая представляет отдельную лабораторную работу.
- **Внутренняя организация каждой lab**: 
  - Основные скрипты (.py) с реализацией методов.
  - Jupyter notebooks (.ipynb) для интерактивного анализа и визуализации.
  - Вспомогательные файлы с тестовыми данными (матрицы, функции).
- **Общие компоненты**: Возможны shared utilities для визуализации (Matplotlib plots) и тестирования.
- **Поток данных**: Входные параметры → реализация алгоритма → вывод результатов + графики.

## Технологический стек
- **Язык**: Python 3.x
- **Библиотеки**: NumPy (для матриц), SciPy (для оптимизации), Matplotlib (визуализация), Pandas (данные).
- **Инструменты**: Jupyter Notebook для демонстрации.

## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/vanya890/NumberMethods.git
   cd NumberMethods
   ```
2. Создайте виртуальное окружение (рекомендуется):
   ```bash
   python -m venv venv
   source venv/bin/activate  # или venv\Scripts\activate на Windows
   ```
3. Установите зависимости:
   ```bash
   pip install numpy scipy matplotlib pandas jupyter
   ```

## Запуск лабораторных
- Перейдите в папку нужной лабораторной: `cd ЛабX`
- Запустите Jupyter: `jupyter notebook`
- Откройте соответствующий .ipynb файл.
