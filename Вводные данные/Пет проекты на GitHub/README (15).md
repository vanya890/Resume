# AI_Study_Colab

## Описание

Репозиторий содержит студенческие лабораторные работы, практические задания и Jupyter Notebook по дисциплинам, связанным с искусственным интеллектом, машинным обучением и программированием на Python.

**Автор:** Куzyk Иван (vanya890), группа 221_327.

## Содержимое

- **KR1_Kuzyk_1.ipynb**, **KR1_Kuzyk_2.ipynb** — контрольные работы.
- **Лабораторная_работа_№2_Модель_нейрона_Кузык_Иван.ipynb** — модель нейрона.
- **Лабораторная_работа_№3_Создание_и_обучения_нейросети_Кузык_Иван_221_327.ipynb** — создание и обучение нейросети.
- **Лабораторная_работа_№5_Кузык.ipynb** — лабораторная №5.
- **Библиотеки_Numpy_Matplotlib_Кузык_Иван_221_327.ipynb** — работа с NumPy и Matplotlib.
- **Практическое_задание_Синтаксис_Python_Кузык_221_327.ipynb** — синтаксис Python.
- **Кузык_Иван_Lab4.ipynb** — лабораторная №4.

## Технологии

- Python
- Jupyter Notebook / Google Colab
- NumPy, Matplotlib
- Машинное обучение (нейронные сети)

## Как открыть

1. Перейдите по ссылкам на файлы `.ipynb` на GitHub.
2. Нажмите кнопку **Open in Colab** (или скачайте и откройте локально).
