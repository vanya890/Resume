# Kursovaya 4 Sem 2 — Cameras

Курсовая работа (4 семестр) — система визуальной локализации робота на основе стереокамер.

## Описание

Приложение на **C# Windows Forms** с использованием **OpenCvSharp** для обработки видеопотоков с двух камер. Программа определяет положение и траекторию робота, анализируя разницу между последовательными кадрами с левой и правой камеры.

## Принцип работы

1. Загружаются два видеофайла (левая и правая камера)
2. Каждый кадр конвертируется в оттенки серого
3. Вычисляется абсолютная разница между текущим и предыдущим кадром для каждой камеры
4. На основе разницы рассчитываются «моторные сигналы» (координаты центра движения)
5. Позиция и угол поворота робота обновляются по дифференциальной модели
6. На карте отображается текущее положение робота и пройденная траектория

## Сборка и запуск

```bash

kursovaya.sln

# Собрать и запустить
```

## Использование

1. Нажмите **«Загрузить левое видео»** — выберите файл (`.avi`, `.mp4`, `.mkv`, `.mov`)
2. Нажмите **«Загрузить правое видео»** — выберите файл второй камеры
3. Нажмите **«Начать обработку»** — запустится анализ видеопотоков
4. Наблюдайте за картой с позицией робота и его траекторией

## Алгоритм

| Шаг | Описание |
|-----|----------|
| Frame capture | Чтение кадров с обеих камер через `VideoCapture` |
| Grayscale | Конвертация в оттенки серого (`ConvertTo(ImageGrayScale)`) |
| Frame diff | Абсолютная разница между текущим и предыдущим кадром (`Absdiff`) |
| Motor control | Расчёт центра масс пикселей с разницей > 30 |
| Robot pose | Обновление позиции: `movement = (leftMotor + rightMotor) * 0.005`, `rotation += (leftMotor - rightMotor) * 0.05` |
| Visualization | Отрисовка робота, сетки и траектории на `PictureBox` |
