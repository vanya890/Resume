## Лабораторные работы с дроном Clover

### Лабораторная работа 1 (lab1_pkg)

**Описание**: Лабораторная работа 1 представляет собой полетное задание для дрона Clover, включающее полет по заданным маркерам и выполнение маневров для фотографирования повреждений.

**Запуск**:
```bash
# Запуск основного скрипта
cd ~/catkin_ws
source devel/setup.bash
rosrun lab1_pkg fly.py
```

**Функциональность**:
- Загрузка карты маркеров из файла `~/catkin_ws/src/clover/aruco_pose/map/cmit.txt`
- Полет по маршруту, определенному ID маркеров
- Выполнение маневров фотографирования на маркерах с повреждениями
- Автоматическая посадка после завершения миссии

### Лабораторная работа 2 (lab2_pkg)

**Описание**: Лабораторная работа 2 включает поиск "полыней" (отсутствующих маркеров) с использованием дрона Clover.

**Запуск**:
```bash
# Запуск через launch-файл
cd ~/catkin_ws
source devel/setup.bash
roslaunch lab2_pkg start.launch
```

**Или запуск скрипта напрямую**:
```bash
cd ~/catkin_ws
source devel/setup.bash
rosrun lab2_pkg ice_search.py
```

**Функциональность**:
- Поиск отсутствующих маркеров (полыней)
- Оптимизация маршрута для эффективного сканирования
- Фотографирование обнаруженных полыней
- Автоматическая посадка на маркере-посадочной площадке (ID 15)

### Лабораторная работа 3 (lab3_pkg)

**Описание**: Лабораторная работа 3 представляет собой поиск маркеров в лесистой местности с использованием дрона Clover, оснащенного лидаром для обхода препятствий.

**Запуск**:
```bash
# Запуск через launch-файл
cd ~/catkin_ws
source devel/setup.bash
roslaunch lab3_pkg start.launch
```

**Или запуск скрипта напрямую**:
```bash
cd ~/catkin_ws
source devel/setup.bash
rosrun lab3_pkg forest_search.py
```

**Функциональность**:
- Поиск маркеров в сложной среде с препятствиями
- Использование лидара для обнаружения и обхода препятствий
- Адаптивное планирование маршрута
- Автоматическая посадка на маркере-посадочной площадке (ID 15)

## Пакеты TurtleBot3

### Запуск симуляции TurtleBot3

Для запуска симуляции TurtleBot3 используйте:

```bash
cd ~/catkin_ws
source devel/setup.bash
roslaunch turtlebot_control_pkg turtlebot3_world.launch
```

Этот launch-файл запускает:
- Симуляцию TurtleBot3 в мире Gazebo
- RViz для визуализации

Параметры:
- `model`: модель робота (burger, waffle, waffle_pi), по умолчанию "burger"
- `x_pose`, `y_pose`, `z_pose`: начальные координаты робота

### Доступные миры симуляции

TurtleBot3 также поддерживает различные миры симуляции:

```bash
# Пустой мир
roslaunch turtlebot3_gazebo turtlebot3_empty_world.launch

# Мир с домом
roslaunch turtlebot3_gazebo turtlebot3_house.launch

# Мир с препятствиями
roslaunch turtlebot3_gazebo turtlebot3_world.launch
```
